# 回收站界面改版 设计

日期：2026-07-10 · 状态：已批准

## 目标

现回收站是纯文字平铺列表，信息弱、无批量操作。改版四个方向：信息更丰富、批量操作、按课程分组、视觉向课程库看齐。

## 布局

沿用全屏面板外壳（返回键、标题、清空回收站按钮不动）。内容区改为：

```
☐ 申论课程 (3)                        ← 组头：全选框 + 课程名 + 数量
─────────────────────────────────
☐ [缩略图] 01.底层逻辑.mp4    12:30   剩余 26 天   ↺ 🗑
☐ [缩略图] 02.审题方法.mp4    45:01   剩余 3 天🔴  ↺ 🗑

（勾选任意项后底部浮出）
已选 N 项    [恢复所选]  [彻底删除所选]
```

## 规格

- **分组**：前端按 `course_id` 分组（组名用 `course_name`），组内保持 deleted_at DESC。组头复选框支持全选/全不选，部分选中显示 `indeterminate` 半选态。
- **行**：复选框 + `VideoCover` 缩略图（16:9，行高约 56px，占位底色）+ 标题（`displayTitle`）+ 时长（`formatMs`，无时长不显示）+ 「剩余 N 天」。剩余 ≤3 天：红色加粗。行尾保留「恢复」「彻底删除」图标按钮，单项操作不必勾选。行样式对齐课程库 `.ca-row` 的视觉 token（hover、圆角、边框）。
- **批量操作条**：有勾选时底部 sticky 浮出：「已选 N 项 · 恢复所选 · 彻底删除所选」。批量彻底删除弹确认（含数量、不可撤销）；批量恢复不确认（可逆）。操作循环调现有单条 ipc（量小，不加后端批量命令）。完成后 invalidate trash/courses/videos 并清掉已消失项的勾选。
- **后端唯一改动**：`list_trashed` SELECT 补 `v.duration_ms`，`TrashedVideo` 加 `duration_ms: Option<i64>`（前端类型同步）。
- **清空回收站**：保留现有行为不变。

## 测试

- Rust：list_trashed 返回 duration_ms（更新现有测试断言即可）。
- 前端：按课程分组渲染；组头全选/半选；勾选后操作条出现、批量恢复调 N 次 restore、批量删除先确认再调 purge；剩余 ≤3 天红色样式（class 断言）；空列表/清空按钮回归。
